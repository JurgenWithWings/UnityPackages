# UnityPackages

```
Created by: JurgenWithWings
```

A collection of Unity packages and editor tools I've made. Each package has its own folder with a README, and one
subfolder per version that contains the `.unitypackage` for that release.

## Packages

| Package | Latest Version | Description |
|---------|----------------|-------------|
| [Scriptable Input System (SIS)](https://github.com/JurgenWithWings/UnityPackages/tree/main/Scriptable%20Input%20System%20%28SIS%29) | [v0.3.0](https://github.com/JurgenWithWings/UnityPackages/releases/tag/ScriptableInputSystem(SIS)-v0.3.0) | A ScriptableObject-based wrapper around Unity's Input System. Read input through Input Channel assets, transform values with chainable Input Processors, detect the active device with Device Profiles, and control action maps with priority-based slots. |
| [Unity Content Drawer](https://github.com/JurgenWithWings/UnityPackages/tree/main/Unity%20Content%20Drawer) | [v0.1.0](https://github.com/JurgenWithWings/UnityPackages/releases/tag/UnityContentDrawer-v0.1.0) | An editor tool that adds a pop-up Project window akin to Unreal Engine's Content Drawer. Frees up some much needed screen space. |
| [Hierarchy Icons](https://github.com/JurgenWithWings/UnityPackages/tree/main/Hierarchy%20Icons) | [v0.2.0](https://github.com/JurgenWithWings/UnityPackages/releases/tag/HierarchyIcons-v0.2.0) | An editor tool that replaces the default GameObject icon in the Hierarchy with the icon of the object's main component, and shows a folder icon for empty GameObjects whose name starts with `f:`. |
